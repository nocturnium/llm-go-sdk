llm-go-sdk

A unified, dependency-light Go SDK for 18 LLM providers — streaming, tool calling, structured outputs, vision, embeddings, and built-in resilience over the standard net/http.

API reference (pkg.go.dev) Source (GitHub) Architecture

Install

go get github.com/nocturnium/llm-go-sdk

Quickstart

import (
    llms "github.com/nocturnium/llm-go-sdk"
    "github.com/nocturnium/llm-go-sdk/pkg/providers/openai"
)

client, _ := openai.New(openai.WithModel("gpt-4o"))
resp, _ := client.GenerateContent(ctx, []llms.Message{
    {Role: llms.RoleUser, Content: "Hello!"},
})

Highlights

  • One llms.LLM interface across 18 providers (OpenAI, Anthropic, Gemini, Groq, Mistral, Ollama, llama.cpp, and more).
  • Streaming, tool calling, an agent loop (RunTools), and typed structured outputs (GenerateTyped[T]).
  • Resilience middleware: retries, circuit breaker, rate limiting, fallback chains.
  • Observability via OpenTelemetry (GenAI semantic conventions) and Langfuse; built-in cost tracking.
  • SSRF-safe by default; Apache-2.0 licensed.
